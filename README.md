# 🎬 בית הקולנוע — הורדות ועדכונים

הריפו הזה מכיל את **קובץ ההתקנה** של בית הקולנוע ואת **רשימת המורשים**.
הקוד עצמו יושב בריפו פרטי נפרד.

## התקנה

להוריד את `BeitHakolnoa-<גרסה>-setup.exe` מ־[Releases](../../releases/latest) ולהריץ.

לאחר ההתקנה, מתחברים עם חשבון Google. אם החשבון ברשימת המורשים — נכנסים לספרייה.
עדכונים מגיעים אחר כך לבד, בלי להוריד שום דבר ידנית.

---

## ניהול המורשים — `allowlist.json`

הקובץ קובע מי יכול להיכנס לתוכנה. כדי לערוך אותו לוחצים עליו כאן ב-GitHub,
לוחצים על העיפרון ✏️, מוסיפים שורה ושומרים. **התוכנה קולטת את השינוי מיד** —
אין צורך בגרסה חדשה.

```json
{
  "updatedAt": "2026-08-06",
  "hashes": [
    "d63223ce967428b45d985e7e8d0db9cbde36f386d353449b5709e15493774ed6"
  ]
}
```

### איך מוסיפים בן אדם

כתובות המייל נשמרות מוצפנות (SHA-256) כדי שלא יהיו חשופות ברשת.
כדי לקבל את המחרוזת של מייל מסוים, מריצים בתיקיית הקוד:

```bash
node scripts/allow.mjs someone@gmail.com
```

ומדביקים את המחרוזת שמתקבלת לתוך `hashes`.

### חלופה בלי הצפנה

אם נוח יותר לעבוד עם מיילים גלויים, אפשר להשתמש בשדה `emails` במקום:

```json
{ "emails": ["someone@gmail.com", "other@gmail.com"] }
```

התוכנה מקבלת את שני הפורמטים, וגם שילוב שלהם. שים לב שבריפו ציבורי
המיילים האלה גלויים לכל אחד.

### הסרת גישה

מוחקים את השורה. המשתמש ייחסם בהפעלה הבאה של התוכנה, או תוך 24 שעות
אם התוכנה כבר פתוחה אצלו.

> Gmail מתעלמת מנקודות ומסיומות `+`, ולכן `a.b+x@gmail.com` ו-`ab@gmail.com`
> מזוהים כאותו חשבון.
